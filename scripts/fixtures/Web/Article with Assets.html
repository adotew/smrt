How attention works

A short, illustrated walk through scaled dot-product attention.

Queries, keys and values

Every token is projected three ways. A query asks what the token is looking for, a key advertises what it offers, and a value is what it hands over once chosen. 

Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V

Scaling

Dot products grow with the dimension dₖ. Large values push softmax into regions with tiny gradients, so the scores are divided by √dₖ.

Multiple heads

Several attention functions run in parallel on smaller projections, then their outputs are concatenated.

Why not one big head?

Separate heads can specialise: one may track syntax while another follows coreference.
